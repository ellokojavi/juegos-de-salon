## D-497 · A lighter process: short CLAUDE.md, D-n only for policy, no translating history, CHANGELOG by month
**Date:** 2026-10-28 · **Status:** current · **Relation:** amends D-316, D-354, D-394, D-300 · **Topics:** agents, publishing
**Context:** the audit of 2026-10-27 (#834, D5; #859) measured what every session pays: `CLAUDE.md` was
35 KB (about 9k tokens) loaded by every session and subagent, `CHANGELOG.md` 314 KB, 459 decisions in
three weeks with 183 of them amended or replaced, and the move to English had cost about 55k changed
lines with 200 Spanish names and 314 Spanish decisions still left. The owner approved all four parts.
**Decision:**
1. **`CLAUDE.md` is about 8 KB of rules and pointers.** The detail of working in parallel, merging and
   publishing, and what each agent and owner tool does moves to `docs/SESSIONS.md`, `docs/MERGING.md`
   and `docs/AGENTS.md`, read on demand; every rule that moved is reachable from a pointer in `CLAUDE.md`.
2. **A D-n is only for a real policy change**: a new rule, a rule that changes or goes, or a choice
   someone would otherwise undo. A small adjustment (a threshold, a wording, a fix, a new flag of an
   existing tool) goes only in its `changelog/` entry and the code comment, with no decision.
3. **History is not translated.** Decisions, CHANGELOG entries and old documents written in Spanish
   stay as they are. A pending Spanish name in `docs/english-renames.json` is renamed only when a PR
   touches that file anyway (`node tools/agents/english.mjs touched`); the processes round no longer
   renames in batches. The D-354 ratchet still fails any new Spanish name.
4. **`CHANGELOG.md` keeps only its newest entry's month.** `changelog.mjs collect` (and `archive`)
   moves every older month to `changelog/archive/<yyyy-mm>.md`; the version still comes from the
   first entry of `CHANGELOG.md`, and readers that look back (the weekly report) read both.
**Why:** each of these was a fixed cost paid by every session or every round for little return; the
rules themselves do not change, only where they live and how much is read by default.
**Consequences:** fewer, weightier decisions; a round without a rename step; sessions start with a
quarter of the context. A rule added later goes to the doc it belongs to, not to `CLAUDE.md`, unless
every session needs it.
