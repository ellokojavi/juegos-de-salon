## D-532 · A learning programme: AI in the game only where it costs nothing per use, and the owner's learning recorded as a deliverable
**Date:** 2026-11-04 · **Status:** current · **Relation:** extends D-395 and D-409 (everything through the lab), D-360 and D-361 (the ideas agent and the lab's experiments), D-528 (lab readiness); keeps D-18 (no model at runtime by default, now stated as a rule) · **Topics:** agents, structure
**Context:** The owner, a product-management lead, asked (2026-11-04) that the project also serve their learning about AI in software, not only the players. The repo's factory (six agents, lanes, one-tap decisions) runs on AI; the game has no model anywhere. The owner cannot and does not want to pay per use: the site earns nothing. Anthropic's terms allow the owner's Max plan for their own Claude Code sessions and forbid routing players' requests through it from any machine ([legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)). The owner is fine with servers as long as they cost nothing per request.
**Decision:** a learning programme, indexed in [docs/LEARNING.md](../LEARNING.md) with one file per piece in `docs/learning/`, under these rules:
- **No variable cost**: nothing in the site bills the owner per use.
- **The owner's plan serves the factory, never the player**: no path from a player's action to the owner's Claude credentials.
- **A model lives in one of three free places**: build time (default: a session generates, a judge filters, static data is committed), the player's device, or the owner's server (an open model on the Mac mini, or a free tier that fails closed). Runtime placements are lab experiments with a measured question, and the game degrades gracefully without them.
- **Each piece runs in three moments**: concept (a page the owner reads, with their decision), build (lab PRs with numbers), learnings (written in the piece file; a step is not done without them). Each piece names its number before building and states how its mechanism is removed.
- **Sessions spend the plan slowly**: read the index and the piece file only; the cheapest model that does the step, Opus only on the moments marked ⚖️; deterministic work as plain scripts; one step per session; the model is called by hand, never from a scheduled job, for generation.
**Why:** the asymmetry between an AI-run factory and an AI-free game is where the owner's learning is; the cost rule and the credentials rule are hard limits, written once so no session rebuilds a proxy to Claude for players; the learnings sections make the learning a deliverable rather than a hope.
**Consequences:** CLAUDE.md's index gets the row. Piece 1 (content generated and judged for 🕵️ Agentes) starts first; its eval is what every later piece uses to pick a model. Piece 6 reopens a live referee (Bachillerato) only on open models in the three places, with `/privacy/` edited in the PR that sends a player's text off the phone (🔴). No new agent: the pieces extend the ideas agent, the processes round and the weekly report.
