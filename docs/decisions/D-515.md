## D-515 · A change no browser can notice runs no end-to-end script
**Date:** 2026-10-30 · **Status:** current · **Relation:** extends D-391 and D-392 (test only what can break); amends D-498 (where `FLAGS` lives) · **Topics:** tests, structure
**Context:** #1058 changed one character of La Copa's home chip and ran all 106 end-to-end jobs: it also reworded a flag's name in `FLAGS`, inside `flags.js`, which almost every page loads, and a comment in `index.html`. Neither can change what a player sees. The owner asked for a mechanism so no PR runs spare tests.
**Decision:** (1) `tools/e2e/since-passed.mjs` drops a file whose patch only changes comments or blank lines (`tools/e2e/inert.mjs`: lines starting with `//`, `/*`, `*`, `*/`, or a whole `<!-- … -->`; a new, deleted or renamed file, or one with no patch, still counts). (2) `FLAGS`, the flags' names, moves to `public/assets/js/flag-list.js`, loaded only by `/labs/`, the panel and the tests, so adding or renaming a flag tests `/labs/` and the panel, not every page. The page graph and the scope guard (D-391) are unchanged: what still reaches a page still runs its scripts.
**Why:** each spare job is minutes of waiting on every PR; comments and the panel's names are the cheapest cases to remove for good.
**Consequences:** a comment-only change goes green with no scripts; `tools/e2e/inert.test.mjs` pins what counts as a comment. A new flag is a row in `flag-list.js` and its card (D-498). `main` still runs smoke plus what a merge reaches (D-496), the net for anything this misjudges.
