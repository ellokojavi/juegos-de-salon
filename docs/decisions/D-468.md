## D-468 · La Copa loads only the game being played, and each Cup game brings its own stylesheet
**Date:** 2026-10-27 · **Status:** current · **Relation:** amends D-331 (the lab games' stylesheets were linked by every page) · **Topics:** cup, structure
**Context:** The 2026-10-27 audit (#834; #844, #845) found that every page built on `cup/game.js` (La
Copa and the 13 solo minigame pages: `/where/`, `/zip/`, `/queens/`…) downloaded the engine and screen
of all 17 Cup games, through the static imports of `cup/games/index.js`, and with them every Timeline
deck (420 KB). And each page linked every Cup game's `style.css`: when 🚂 Tren en Vilo left the lab, one
`<link>` went into 13 other games' pages.
**Decision:**
- **`cup/games/index.js` is a map of loaders.** `CODE[id]` fetches a game's engine and screen with
  literal `import()`s (the timeline games also `mazos.js`, and so the decks); `loadGame(id)` fetches it,
  with the games it plays inside it (the final and a day of three: all), and registers it in `JUEGOS`,
  which starts empty. `GAME_IDS` names them all without loading any; `loadAll()` is for the tests and the
  end-to-end scripts that generate a game themselves; `engineOf(id)` gives a loaded game's engine
  (`desglose.js` no longer imports six engines).
- **The screens that need a game wait for it** (`conJuego()` in `cup/game.js`): the waiting room of a
  day, playing it, its trial and a standalone game. The metadata stays synchronous: names, rules
  (`rules.js`, with the lab games' `texts.js`), calendar and variants come from `rules.js` and
  `cup/engine.js` as before.
- **A Cup game's stylesheet comes with its screen**: its `ui.js` runs
  `await loadCss(new URL('./style.css', import.meta.url))` (`assets/js/load-css.js`, which adds the
  `<link>` once and resolves on `load`, or on `error` so the game still plays), so the module, and the
  game's first screen, waits for it: no unstyled flash. No page links a Cup game's stylesheet;
  `cup/games/lazy.test.mjs` keeps it that way.
- **The end-to-end scope still sees everything:** `tools/e2e/affected.mjs` already follows literal
  `import()`s and `new URL('<file>.css', import.meta.url)`, so a page's closure is the same as before.
**Why:** Measured with Chrome against the local site, first visit with `?test`, before → after:
`/where/` 141 requests and 2,731 KB → 72 and 1,572 KB; `/zip/` 140 and 2,529 KB → 67 and 1,173 KB;
`/cup/` 141 and 2,544 KB → 66 and 1,170 KB. A game screen's only extra cost is one round trip for its
own code when it opens. Adding a Cup game now touches no other game's page.
**Consequences:** `rules.js` (194 KB, the four languages) still loads whole: splitting it by language
is a larger refactor, left for later. The Timeline decks still load together when a timeline game
(⏳, 📅 or the final) is played, since its generator is synchronous. A script that reads `JUEGOS` in
the page first awaits `loadAll()`.
