## D-511 · 📦 Enviar a La Bodega, a button next to 🚀 on every card being tried
**Date:** 2026-10-29 · **Status:** current · **Relation:** extends D-480 (the same request, the same job, the same states on the card) and D-510 (moving a launched flag's card) · **Topics:** structure
**Context:** after D-510 the owner asked (2026-10-29) for a button that sends a card to La Bodega the way 🚀 Publicar para todos publishes it, for future releases and features.
**Decision:** every card under 🧪 / ✨ Mejoras en prueba shows **📦 Enviar a La Bodega** to the owner. Confirming writes `labsPublish/<card id>` with `kind: 'bodega'` (Firebase rules allow `publish` or `bodega`); the Mac mini's `lab-publish-watch` hands it to the same headless session (`tools/jobs/prompts/lab-publish.md`) on branch `bodega-<id>`, which only moves the card: as 🚀 Lanzado if its flag is on *all*, else as 💤 No prosperó. No gate, flag or game code changes. The card shows the request's states as for 🚀.
**Why:** moving a card is a change to `public/labs/index.html`, so it needs a PR; the owner should not have to ask a session for it.
**Consequences:** `firebase/labs-publish.test.mjs` checks the kind, `tools/agents/lab-publish.test.mjs` the branch, `tools/e2e/labs/publish.mjs` the button and its sheet.
