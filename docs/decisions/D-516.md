## D-516 · A change to a module runs only the pages that use what it changed
**Date:** 2026-10-31 · **Status:** current · **Relation:** extends D-391, D-392 and D-515 (test only what can break) · **Topics:** tests, structure
**Context:** of the last 40 PRs, 21 ran all 106 end-to-end jobs. The usual cause was a shared file every page loads: a new text in `i18n.js`'s `COMMON` (12 PRs), one function of a shared module (`uno-al-dia-ui.js`, `stats.js`), or a file no page loads (`assets/og/huellas.json`, the manifests). The owner asked to extend D-515's logic to PRs that change real code.
**Decision:** (1) `tools/e2e/narrow.mjs` reads a site module's patch and names what it changed: the top-level declarations, or, in a texts object keyed by language (`COMMON = { es: {…}, en: {…} }`), the keys. `since-passed.mjs` sends that file as `public/f.js#uses=a,b`. (2) `affected.mjs` keeps only the pages where a loaded file uses one of those names where it runs; a module that uses them only inside its functions passes those functions' names on (`usedOn`, `reach`). (3) `READ_BY` declares files whose readers are known: the manifests run `installable.mjs` and `smoke.mjs`, the link cards' fingerprints none. Anything unclear keeps the whole file: an import or other top-level code, a change to a texts object's shape, a name no other file writes, a scan that does not balance, a patch that does not fit.
**Why:** a page that never names what changed cannot notice the change; the code says who names what, so it is derived, not declared (D-391).
**Consequences:** measured on those 21 PRs, about 1,670 jobs instead of about 2,200: a text or flag PR drops from 106 to 19–48; changes to names every page uses (`trackVisit`, `menu`) still run everything, as they should. Matching is by word, so a common name over-tests, never under-tests. `tools/e2e/narrow.test.mjs` pins it. The net stays: `main` runs smoke plus what a merge reaches (D-496).
