## D-552 · Dudo's classic rules, as a Chilean cacho table plays them
**Date:** 2026-11-12 · **Status:** current · **Relation:** amends D-490 · **Topics:** modes
**Context:** Players from a Chilean cacho table sent feedback on the 📜 Classic rules: going into aces asked for half plus one (4 cuadras → 3 ases), the obligada round showed up with two players left, nobody saw their own die in it, and calzar was possible "always".
**Decision:** The owner chose, on 2026-11-12, for the classic rules:
1. **Into aces is half rounded up**, as in the public game (6 fives → 3 aces, 5 fives → 3). Leaving aces stays double plus one. Replaces D-490 point 1.
2. **Calzar** is the same as in the public game: from half the dice on the table and with three players or more, also for a player with one die. Replaces D-490 point 2 (the one-time calzar hint stays).
3. **The obligada round is closed**: each player sees only their own dice, as in a normal round; the rivals' dice are not shown and nothing travels in the clear. Replaces D-490 point 5.
4. **No obligada round with two players left.** Replaces D-490 point 8.
**Why:** it is how the players' table plays cacho, and the owner agreed with each point; the classic switch should match the table it is named after.
**Consequences:** `minBid` loses `halfPlusOne`, `calzarOk` loses its rules argument, `buildState`'s `rules` loses `halfPlusOne` and `open`; the room no longer sends obligada dice in the clear; the strings for the hidden own die and the one-die calzar line are gone. Saved games resume with the new rules.
