## D-451 · The Claude rounds run from launchd on the Mac mini
**Date:** 2026-10-26 · **Status:** current · **Relation:** amends D-440 · **Topics:** jobs, agents
**Context:** The daily processes round and the weekly report were scheduled tasks. The desktop app's tasks ran only while the app was open and stopped unseen after 2026-10-18; claude.ai cloud tasks cannot reach the Mac mini, where the keys, `gh`, Chrome and the mail account live.
**Decision:** Both are `mac` jobs in `tools/jobs/jobs.json` with a calendar time (`at`), installed by `jobs.mjs install` as launchd jobs that run `tools/jobs/claude-task.mjs`: `claude -p --permission-mode auto` reading the same prompt file from origin/main. The `app` kind is gone.
**Why:** launchd needs only the Mac on and `claude` signed in, runs a time missed during sleep on waking, and `jobs.mjs` already logs, locks and records each run, so `jobs.mjs status` shows them next to the other jobs.
**Consequences:** No desktop or claude.ai task for the project; the old ones are deleted. `round-watch` still catches a missed round, and its issue now points at `jobs.mjs status` and the log. Moving machines means installing and signing in `claude` there.
