## D-543 · A preview only when there is something to look at
**Date:** 2026-11-08 · **Status:** current · **Relation:** amends D-429 · **Topics:** publishing
**Context:** D-429 built a preview of every PR, including PRs that only change docs, tools or tests, where there is nothing to see.
**Decision:** `preview.yml` builds and comments a preview only when the PR changes something under `public/` other than `*.test.mjs`; otherwise it notes "no preview" in its log and stops.
**Why:** the owner (2026-11-08): no time spent building a preview when there is nothing to preview.
**Consequences:** a docs- or tools-only PR gets no 🔍 comment. A preview left from an earlier push stays until the PR closes.
