## D-524 · The language selector shows only the flags
**Date:** 2026-11-01 · **Status:** current · **Relation:** amends D-231 (flag and code on each button) · **Topics:** languages
**Context:** The toggle carried the flag and the code (🇪🇸 ES) on each button, and took too much width next to the round buttons of the top bar.
**Decision:** Each button shows only its flag; the language name stays in `title` and `aria-label`. The owner asked for it to save horizontal space (PR #1118).
**Why:** The flags alone are recognisable, and the narrow-phone rule that stacked flag over code is no longer needed.
**Consequences:** C-3 in docs/CANONES.md describes the flags-only toggle; e2e scripts pick a language button by its `lang`, never by its text.
