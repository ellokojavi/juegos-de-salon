## D-549 · Every game's name is translated, and a test checks it
**Date:** 2026-11-09 · **Status:** current · **Relation:** — · **Topics:** languages
**Context:** Aletazo reached production named "Aletazo" in English and Portuguese: the texts were translated but the name was not, and nothing caught it. The owner was surprised and asked for a rule and a check so no game reaches players with a disparity between languages.
**Decision:** A game's name is translated to every language like any other text (C-3). It stays the same as the Spanish one only for a reason a player would accept (a proper name, a word that is already the same), written in `SAME_NAME` in `public/assets/js/game-names.test.mjs`. The test also fails a game with a missing name, a stale `SAME_NAME` entry, and a La Copa `texts.js` whose `juego.nombre` differs from `games.js` in any language. Aletazo is now Flap in English (its folder's name) and Bate-Asa in Portuguese.
**Why:** The parity test checks that keys exist in every language, not that their values were translated; a name copied across languages passes it. The name is the first thing a player reads.
**Consequences:** A new game, or one leaving the lab, fails `tests` until its name is translated or its same name is justified. Launching a game (moving it to production) includes reviewing its name in each language.
