## D-537 · On a game's cover, the language is a button in the top bar
**Date:** 2026-11-07 · **Status:** current · **Relation:** amends D-231 (one selector, now also in a compact form); amends D-344 (the cover goes from the title straight to the modes) · **Topics:** languages
**Context:** the owner: choosing a language is set and forget for a returning player, so the full three-flag toggle under every game's title is space spent on every visit for a choice made once. Since D-536 a first visit already opens in the browser's language.
**Decision:** on game covers (the party games' intros and the Cup games' own pages) the toggle leaves the cover: the top bar shows one round button with the current flag, before sound, and a tap opens the same `langToggle()` under it. La Copa (its home and its invitation) and Uno al día follow the same rule (the owner, 2026-11-07); the home page, Rankings and Privacy keep the full toggle where it is. It first showed behind the flag `compact-lang`; the owner published it for everyone on 2026-11-07, and the gate came off in a later PR (`landing-fold-flake`), so the button is placed before the first paint on every visit.
**Why:** a player who lands on a shared link in the wrong language can still switch without leaving the game; everyone else sees the modes right under the title.
**Consequences:** `coverLangToggle()` and `langButton()` in `public/assets/js/i18n.js`, the `.lang-btn` / `.lang-pop` styles in `base.css`. The button is placed before the first paint, with no flash of the old toggle, also on a first visit with no cached flags (a late flags/ answer used to push the start button below the fold at 320 px, `tools/e2e/landing-fold.mjs`).
