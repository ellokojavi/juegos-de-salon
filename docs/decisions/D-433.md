## D-433 · Uno al día's first attempt counts from its start; La Copa's clock survives another phone
**Date:** 2026-10-23 · **Status:** amended by D-465 · **Relation:** amends D-230 (the first finished attempt counted) · **Topics:** random-and-daily, cup, anti-cheat
**Context:** the owner noticed that leaving a game midway (a back swipe, D-432) and starting again
restarts it, which is unfair to whoever played their attempt to the end. In Uno al día only a finished
game was recorded, and nothing marked an attempt as started: a bad run could be dropped (Back, reload,
closing the tab) and the same board, already known, played again from zero until one was finished,
and that one counted as the first. La Copa locks the start on the server and resumes the attempt from
the phone's save, but on another phone, or with the browser's memory cleared, the same board started
over with a new clock.
**Decision:** the owner chose that an attempt counts from the moment it starts, and an unfinished one
**scores 0 for the day**.
- **Uno al día** (`uno-al-dia.js`, `uno-al-dia-ui.js`): starting today's first attempt leaves a marker on
  the phone (`juegos-de-salon:uno-al-dia:empezado`) and, with a player, in Firebase
  (`unoAlDiaInicio/<jid>/<n>`, the server time, written once). A **solo game** left halfway goes on where
  it was, with its moves and its active time (saved on every move and when the page is hidden), and the
  intro says so; a **group game** (El Ahorcado, Batalla Naval, Dudo, Generala) cannot resume, so going
  back to it counts 0 and the new game is practice. A day that ends with its attempt unfinished counts 0
  for that day, recorded as its result. An attempt started on another phone of the same player and never
  finished also counts 0 there. The intro of the first attempt adds the rule: «Vale tu primer intento: si
  no lo terminas, queda en 0.» Without a player, the marker lives only on the phone. With an
  attempt left halfway, **the way in skips the die** (the owner's request, 2026-10-23): the home page's
  ▶ and /today/'s Jugar go straight to today's game, and for a solo game they say «▶ Seguir jugando»
  (`estado().inProgress`, `rotuloJugar`); a group game's keeps its label, since going back counts 0.
- **La Copa** (`cup/game.js`): a day resumed (Seguir jugando) without its save on this phone takes its
  clock from when the day started on the server (`started/<d>/<pid>`), not from zero, and says so.
- **In the lab first** (D-409), with the cards `#seccion-uad-intento` and `#seccion-copa-reloj`. La
  Copa's case is tried without two phones through the demo `?test&demo=resumed` (a sample cup where the
  day started 4 minutes ago elsewhere), linked from its card; `tools/e2e/cup/resumed-clock.mjs` checks
  it. **For everyone since 2026-10-23:** the owner validated both in the lab; the key checks are gone and
  the cards moved to La Bodega, 🚀 Lanzado.
**Why:** a result that can be retried until it is good is not the same challenge for everyone. Locking
the start is how La Copa already worked on the same phone; this closes the ways around it.
**Consequences:**
- A lost day is recorded as played with 0: it keeps the streak and its streak bonus (D-414), as starting
  counts as playing. It is charged its time so far (at most a day), so it never ranks above an honest 0.
- La Copa's clock from the server counts all the time since the start, also while the page was not
  open: the cost of losing the save, which on the same phone does not happen.
- Clearing the browser's memory still resets the attempt of a player without a player profile; those
  attempts reach no ranking.
- `daily-attempt.test.mjs` checks the marker, the resume, the 0 and the streak;
  `uno-al-dia-jugador.test.mjs` the Firebase start against the test store and the rules.
**Later (2026-10-27):** a day's points (`w`, `p`) need its start in `unoAlDiaInicio/` first; the phone writes it before uploading a result if the attempt's start did not get through (D-465).
