## D-513 · Offensive names: a word list on sign-up and an owner rename tool
**Date:** 2026-10-29 · **Status:** current · **Relation:** — · **Topics:** rankings
**Context:** The rankings are public and every player picks their own name (up to 20 characters). Among friends that was fine; before posting the site to strangers (D-512) the owner asked for a control over offensive names.
**Decision:** Two layers. (1) **On sign-up**, behind the flag `name-guard`, `name-guard.js` refuses a new name with an insult, slur or sexual word in the four languages, undoing accents, capitals, repeated letters, spaced letters and 0→o-style swaps; short or name-like words (culo, puta, verga, porra, nazi, cock…) count only as a whole word, so Película, Computadora, Vergara, Porras, Nazir or Hancock pass. Signing in with an existing name is not checked. (2) **After the fact**, the owner renames a player with `tools/firebase/rename-player.mjs` (dry run by default): the name, its search key and every table row, in one write, since the rules already require each row's name to be the player's. The player keeps scores and PIN; their phone reads the server's name on every page (`refrescarNombre`), so its next scores are not refused.
**Why:** a list catches the obvious at no cost and with no server; a determined player can get around any list, and the rename covers that without a moderation queue. The list is in the client and the rules do not repeat it: it is a courtesy, not a wall.
**Consequences:** Names in La Copa (shared only by code among friends) and in rooms are not checked. A false positive is fixed by editing the list and its test (`name-guard.test.mjs`, which also lists real names that must pass).
