## D-496 · Publishing runs smoke plus what the merge reaches, not the whole suite
**Date:** 2026-10-28 · **Status:** current · **Relation:** amends D-302 and D-308 (publishing ran the whole end-to-end suite whenever the merged tree was not identical to one a PR tested) · **Topics:** publishing, tests
**Context:** the 2026-10-27 audit (#834, #858): at about 28 merges a day `main` moves between a PR's
last run and its merge, so the tree that lands is rarely the one the PR tested, and 10 of 30 sampled
Publish runs ran the whole 26-job suite (~8 minutes each) to retest files their PRs had already
passed.
**Decision:** `tools/e2e/already-tested.mjs` gains a third answer. When the tree has no mark and the
commit is a merge whose second parent (the PR's head) carries its `e2e-head-<sha>` mark (D-392, from a
green PR run of this repo), `publish.yml` passes the first parent as `base` to `e2e.yml`, which runs
`smoke.mjs` plus the scripts `affected.mjs` selects for `git diff base HEAD`: what the merge brings to
`main`, also when that reaches no script (smoke always runs, `ci.mjs --smoke`). That run never leaves
the tree's mark and never closes the "main is red" issue, since it tested only part of the tree. Any
other case (a direct push, a squash, a PR head that did not pass, asking GitHub fails) runs the whole
suite as before, and the same tree already tested still skips it (D-308).
**Why:** the PR already tested its own files; what is new on `main` is the code they now meet, and the
graph says which scripts load it. The owner asked to stop paying the whole suite for that (#858).
**Alternatives discarded:** requiring branches to be up to date before merging (every PR would rerun
on each merge of another); keeping the whole suite (the cost the audit measured); adding more marks or
layers (the issue asks to stop growing the test-scope stack: this reuses the PR head marks that exist).
**Consequences:** publishing a typical merge takes the time of its scope plus smoke, not ~8 minutes.
The guarantee is weaker: an interaction between two PRs that reaches a script neither PR's diff
reaches is no longer caught before publishing. `smoke.mjs` still opens every page, and a hole in the
graph is still a guard's job (D-391). `already-tested.test.mjs` tests the decision and that smoke always runs.
