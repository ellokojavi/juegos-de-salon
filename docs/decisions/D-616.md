## D-616 · A contributor's PR does not stay stuck: one rerun, the red read, a week's silence goes to the owner
**Date:** 2026-11-24 · **Status:** current · **Relation:** extends D-568 and D-573 to outside PRs · **Topics:** agents
**Context:** D-573 rescues the owner's red PRs; an outside PR had only the contributions agent (D-568), which looks only when the PR changes and never reruns, pushes or merges. On 2026-11-24 #1826 sat red for a test `main` had broken (#1836 fixed it), and nothing would have moved it; a fork that does not let maintainers edit its branch can never be brought up to date by the merge queue (D-586); and a contributor who goes silent leaves the PR open forever.
**Decision:** three pieces, none touching the contributor's branch. (1) The hourly heartbeat (`pending.mjs nudge`) reruns the failed jobs of an outside PR's red commit once, after an hour with no push, and says in one line it may not be their code (mark `contrib-rerun <sha>`). An hour later, still red, `contributions.mjs check` lists it: the agent reads the log and either explains the fix to the contributor, or, when the failure is not theirs (a test their files never reach, or red on `main` too), tells them so and tells the owner with `ready`, so a session of the owner's fixes `main`. (2) The agent asks a fork with "Allow edits by maintainers" off to turn it on, and names it in the `ready` line while it is off. (3) A contributor silent 7 days with something still asked of them: the agent opens the owner's one-tap decision with `contributions.mjs stale` — Yes takes the work over on a branch of ours with them as co-author (in Labs or published), No closes it with thanks, unticked waits.
**Why:** a red check that is not the contributor's fault should not cost them days; anything that needs the owner's authority reaches the owner as one tap, and the owner reads it (their words, 2026-11-24).
**Consequences:** the rerun happens once per commit, so a real failure is not hidden: the second red is read and explained. The takeover runs in the processes round from the queued task, never as a push to the contributor's branch.
