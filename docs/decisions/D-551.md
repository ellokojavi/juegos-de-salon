## D-551 · Testing shortcuts live in the tester tab, never on the cover
**Date:** 2026-11-11 · **Status:** current · **Relation:** amends C-12 · **Topics:** tests
**Context:** ¡Al toque!'s cover carried a «La corrida de hoy» button only useful for testing, and trying one new microgame meant waiting for it to come up at random. The owner asked that testing controls go in the «T» tester tab, so the cover always looks as a player sees it.
**Decision:** A control that only speeds up testing (play one level, game or microgame directly, jump to a state, simulate an end) is registered with `setTesterContext` (`tester-ribbon.js`) behind `labAccess`, and never added to the cover or any player screen. Players never see it.
**Why:** A cover with test controls is not the cover players get, so what the owner reviews differs from what ships; the tab already exists for lab key holders.
**Consequences:** ¡Al toque!'s tab gets «Probar un microjuego» (any of the 29) and «📅 Corrida de hoy»; ¡Flap!'s «Empezar en nivel» already followed this. The texts of tester controls can stay in Spanish, as the tab's own controls do.
