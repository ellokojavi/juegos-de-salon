## D-530 · Version 1.0: from here the three numbers mean major, minor and patch
**Date:** 2026-11-03 · **Status:** current · **Relation:** extends D-300 (the level of each changelog entry) · **Topics:** publishing
**Context:** The site went from 0.1 to 0.247 with every change a patch or a minor, because before 1.0 the first number meant "not finished yet". The owner said Juegos de Salón is mature enough to be called 1.0 and asked to number versions from that level on.
**Decision:** The PR that records this decision carries `level: major`, so the version goes from 0.247.x to **1.0.0**. From then on each entry in `changelog/` picks its level by what the player gets:
- **patch** (1.0.0 → 1.0.1): a fix, an adjustment, a text, anything internal (tools, docs, tests, agents).
- **minor** (1.0.1 → 1.1.0): something new a player can see: a game published, a new mode or feature, a lab card moved to La Bodega for everyone.
- **major** (1.1.0 → 2.0.0): only when the owner asks for it, for a jump in the whole product (the way 1.0 was). An agent never chooses `major` on its own.
- **When to keep the level and when to raise it**: one PR is one entry and one step, however much it brings; ten fixes in a day are ten patches, never "enough for a minor". The middle number moves only when there is something to announce (the test: would it go in a message to players?). Something new still in the lab is a patch: it becomes a minor the day it comes out for everyone (its `publish-<id>` PR). A minor resets the last number (1.3.7 → 1.4.0), a major resets both.
- **`changelog.mjs` suggests the level** from the diff (`suggestLevel`): minor for a new id in `games.js` or a `publish-<id>` branch, patch otherwise; never major. `new` with no level takes the suggestion, and `check` warns (does not block) when the entry's level differs, so the PR can keep its own with a reason.
**Why:** a 0.x version says "beta" to anyone reading it, and the site has been played for months; with 1.0 the first number stops being a placeholder and a minor marks something worth announcing.
**Consequences:** `changelog.mjs` already bumps `major` to `X+1.0.0`; nothing in the tools changes. `changelog/README.md` and `docs/MERGING.md` say which level to pick.
