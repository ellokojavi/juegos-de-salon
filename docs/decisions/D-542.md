## D-542 · Every game is one more game: no subset in the code, the docs or the work
**Date:** 2026-11-08 · **Status:** current · **Relation:** extends D-198 · **Topics:** structure
**Context:** D-198 dropped the word "minigame" from what the player reads, but the split lived on inside: two lists in `games.js` (`GAMES` and `SUELTOS`), each joined by hand in some 25 places and walked alone in others, and docs that spoke of "La Copa's mini-games" or "every minigame". The owner noticed that changes meant for the games reached only part of them (2026-11-08): "mini" only says a game is short; it is no taxonomy.
**Decision:** there is one kind of game. A change for the games reaches every game in the same PR, or the game left out says why in its spec. Code walks `ALL_GAMES` from `games.js`; `GAMES` and `SUELTOS` stay apart only for how a game is built. No doc, agent or decision calls a group of them "minigames" or "Cup games" as another kind. Written as canon C-21.
**Why:** the owner's request; a subset list is how a fix lands in half the games without anyone choosing it.
**Consequences:** `ALL_GAMES` replaces every hand-made union, and `all-games.test.mjs` fails on a new one. The checks that still walk only `GAMES` (`games.test.mjs`, `structure.mjs`, `memory.mjs`, `conformance.test.mjs`, the cards in `og.mjs`) are extended to every game one PR at a time. Cuarto Rey's *minijuegos* (what a card orders) are not games of the site and keep their name.
