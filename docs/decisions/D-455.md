## D-455 · A lab game may keep its own leaderboard, outside the Todoterreno
**Date:** 2026-10-26 · **Status:** current · **Relation:** amends D-212 ("Qué cuenta": the lab did not count) · **Topics:** rankings, labs
**Context:** D-212 said that only the home page's games count in the rankings, "sin el laboratorio". In
practice Julepe, a lab game, already recorded its wins (D-215), and Stick Ninja got its leaderboard on its
cover and result like every game played alone (PR #799), because a game without its table on screen does
not follow the canon. The rule and the practice disagreed.
**Decision:** A lab game may keep **its own table** in `records/` (its id, like `stick` or
`julepe_victorias`), shown on its cover and result with the same pieces as any game (`bloqueTabla`,
`avisoPartida`, `finDePartida`, D-212, D-249, D-274), and its finished games count in the player's
history. It stays **outside the Todoterreno**, which sums only the games out of the lab
(`SUELTOS.filter(g => !g.labs)` in `jugador.js`), and outside "Copa" for a lab Cup. A course or board
chosen in the link (`?seed=`) still never counts. When the game leaves the lab, its table goes on as it
is and it joins the Todoterreno from then on.
**Why:** The owner's request (2026-10-26): every game has its ranking on screen, and a game tried with
friends in the lab is tried with its leaderboard, which is part of what is being tested.
**Consequences:** Scores made in the lab stay in the table after the game is published: a lab tester may
start ahead. The rules accept any table's shape (C-16), so nothing changes in Firebase. A lab game
whose page is in one language fixes the rankings' language with `fijarIdioma(lang)` (`ranking.js`).
