## D-397 · The home page search lists the games whose name matches first
**Date:** 2026-10-20 · **Status:** current · **Relation:** extends D-390 (the dropdown) · **Topics:** home
**Context:** the dropdown listed what it found in the home page's order, so "toque" put Toque y Fama: Palabra
first and could show a game whose tagline only says "toquen" before others. The owner asked that a match
in the game's name count more than its other data.
**Decision:** `ranked()` in `public/labs/home/search.js` orders the games found by where each typed word
matches best: the name in the player's language (4, half a point more when the name starts with it), the
name in another language (3), the game's keywords (2), its type (1.5, because "Cartas/Dados" holds both),
its tagline (1). Between equals, the shorter name first, then the home page's order. Which games are found
does not change, nor the list "Ver los n juegos" filters.
**Why:** a player who types part of a name is looking for that game.
**Consequences:** "toque" gives Toque y Fama, then Toque y Fama: Palabra, then Reinas; "cartas" puts Julepe
and Cuarto Rey before the dice games. `public/labs/home/search.test.mjs` checks the order.
