- **The countdown's last digit is no longer cut off on Safari (iPad, iPhone).** The big number asked Bangers for a bold it does not have, and Safari faked it by thickening each letter to the right, past its box. Now no browser fakes a weight or slant (`font-synthesis: none`), the big display text keeps room for the letters' lean (`--ink-overhang`), and `font-synthesis.test.mjs` fails if a rule asks Bangers for a weight it is not loaded in.
